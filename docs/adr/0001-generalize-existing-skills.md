# Generalize an existing skill set rather than authoring from scratch

This repo's skills are produced by extracting a proven, repo-specific workflow
skill set and stripping its couplings to that one repository, rather than
authoring skills from scratch. The decision is to start from working,
battle-tested skills and generalize them, keeping the conventions that have
proven useful (GitHub, separate bootstrap and modeling skills, multi-context
support) while removing anything that only applies to a single repo.

## Considered Options

- **Re-author from scratch** — rejected; redoes proven work, likely worse.
- **Copy an existing generalized fork verbatim** — rejected; available forks had
  diverged (dropped GitHub specifics and multi-context, merged skills we want
  kept separate).
- **Extract and generalize the proven set** — chosen.
